Middleware to create error-free multi-region applications

## Installation

You can install the package via Composer:

```bash
composer require tpetry/laravel-multi-region
```

You may publish all of the package's resources at once:

```bash
php artisan vendor:publish --tag="laravel-multi-region"
```

Or, you may publish each resource individually:

### Publishing the Configuration File

```bash
php artisan vendor:publish --tag="multiregion-config"
```
